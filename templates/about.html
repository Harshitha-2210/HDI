Methodology

How the prediction pipeline works

This version predicts HDI from ten real-world socioeconomic and infrastructure indicators instead of fitting the HDI formula itself.

Infrastructure

Electricity access, internet users, and water access capture basic services and connectivity essential for development.

Health & Demography

Infant mortality, health expenditure, and fertility rate provide proxies for health systems and population dynamics.

Labor & Environment

Unemployment, female labor participation, urbanization, and CO2 emissions capture economic and environmental dimensions.

Project Pipeline

How this application was built

  1. Environment setup

    NumPy, Pandas, Matplotlib, Seaborn, and scikit-learn form the core toolkit for analysis and modeling.

  2. Dataset

    Real-world country-year observations (4,484 rows) spanning multiple development tiers and ten realistic socioeconomic and infrastructure indicators.

  3. Exploratory data analysis

    Strip plots, distribution plots, a correlation heatmap, and scatter plots reveal how each indicator relates to the final HDI score.

  4. Preprocessing

    Features and the target are separated and the data is split into training (~80%) and test (~20%) sets by country, so no country appears in both. Missing values are median-imputed using training-set medians only.

  5. Model training

    A standardized Linear Regression model is compared with a Random Forest Regressor on the held-out countries, confirmed with 5-fold country-grouped cross-validation, and the best performer is serialized.

  6. Serialization

    The selected model and scaler are pickled so the Flask app can load them instantly without retraining.

  7. Web application

    Flask serves the home, prediction, insights, and methodology pages, turning the model into an interactive tool.
